# NOVA, le studio de cadrans pour votre montre connectée

Plus de 150 cadrans animés, un studio pour créer les vôtres, votre activité en un coup d'œil et des séances lancées depuis le téléphone. Une alternative à l'application d'origine de votre montre, pour aller beaucoup plus loin dans la personnalisation.

Gratuit, sans compte : vos données restent sur votre téléphone.

- Site et téléchargements : https://nova-montre.vercel.app
- Application web : https://nova-montre-web.vercel.app

## Installer

**Android** : téléchargez `NOVA-x.y.z-android.apk` dans la dernière version (onglet Releases), ouvrez-le et autorisez l'installation. Les nouvelles versions s'installent par-dessus, vos créations sont conservées.

**iPhone** : le fichier `NOVA-x.y.z-ios.ipa` s'installe avec Sideloadly ou AltStore et votre identifiant Apple (gratuit, à renouveler tous les 7 jours). Sans installation : ouvrez l'application web dans le navigateur Bluefy.

## Mises à jour

L'application vous prévient dès qu'une nouvelle version est disponible. Toutes les versions sont dans l'onglet Releases.

NOVA est une application indépendante.
