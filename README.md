# NOVA, le studio de cadrans pour montres Oraimo

Téléchargements officiels de l'application NOVA (Android et iPhone).

- Site et téléchargements : https://nova-oraimo-app.vercel.app
- Application web : https://nova-oraimo.vercel.app

## Installer
**Android** : téléchargez `NOVA-x.y.z-android.apk` dans la dernière version (Releases), ouvrez-le et autorisez l'installation depuis cette source.

**iPhone** : le fichier `NOVA-x.y.z-ios.ipa` s'installe avec Sideloadly ou AltStore, avec votre identifiant Apple (gratuit, à renouveler tous les 7 jours). Sans installation : ouvrez l'application web dans le navigateur Bluefy.

NOVA n'est pas une application officielle Oraimo.
